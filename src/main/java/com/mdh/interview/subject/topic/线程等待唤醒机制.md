# 线程等待唤醒机制

## 三种让线程等待和唤醒的方法
~~~
1.使用Object中的wait()方法让线程等待,使用Object中的notify()方法唤醒线程
2.使用JUC包中Condition的await()方法让线程等待,使用signal()方法唤醒线程
3.LockSupport类可以阻塞当前线程以及唤醒指定被阻塞的线程
~~~ 

## 
~~~
1.wait/notify 是 Object 原生方法，仅支持单队列、随机唤醒，需配合 synchronized；
2.Condition（ConditionObject）基于 AQS 实现，支持多条件队列、精准唤醒，功能更丰富；

await () 核心是 “释放锁→入 Condition 队列→park 挂起”，
signal () 核心是 “移节点到 AQS 队列→unpark 唤醒”。
~~~
