## 秒杀防止超卖方案
~~~
秒杀4个关键点
1.预热库存到Redis
    秒杀开始前全量加载，不查库
    
2.Redis原子扣减
    当请求进行，直接执行原子扣减指令，无锁切绝对安全
    
3.判断结果
    扣完>=0 就是成功，发送MQ异步队列
    扣完<0就回滚，直接返回库存不足
    
4.后台异步落库
    消费MQ，写数据库持久化
    
    
预约制：用户提前预约才能下单
限购制度：一个用户只能买一件，接口层直接拦截重复下单
下单自动取消：15分钟未支付自动释放库存，避免占库存不付款
前端拦截+风控： 验证码、设备限制、黑名单等多层防护


秒杀超卖 = Redis预热 + 原子扣减(核心) + MQ异步落库(关键) + 业务层控制(保障)
~~~
