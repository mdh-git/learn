# JVM参数调优

## 设置堆空间大小
~~~
为了防止垃圾收集器在初始大小、最大大小之间收缩堆产生额外的时间，通常把最大、初始化大小设置相同的值

-Xms： 设置堆初始化的大小
-Xmx： 设置堆最大的大小

默认单位是k，字节

最大大小默认是物理内存的1/4，初始化大小是物理内存的1/64
堆太小，可能会频繁的导致新生代和老年代的垃圾回收，会产生STW，暂停用户线程
堆内存大肯定是好的，存在风险，假如发生了Full GC，它会扫描整个堆空间，暂停用户线程的时间长
设置参考推荐：尽量大，也要考虑一下当前计算机其他程序的内存使用情况
~~~

## 设置虚拟机栈
~~~
每个线程默认会开启1M的内存，用于存放栈帧、调用参数、局部变量，但一般256k足够用。通常减少捏个线程的堆栈，可以产生更多的线程，但实际上还受限于操作系统

-Xss  对每个线程stack大小调整 -Xss 128k

~~~

## 设置年轻代晋升老年代阈值
~~~
-XX：axTenuringThreshold = 15  默认值为15
取值0-15
~~~

## 设置垃圾回收器
~~~
JDK8 默认
-XX：+seParallelGC    
-XX：+seParallelOldGC    

设置成G1
-XX:+UseG1GC 
~~~
