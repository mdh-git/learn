# MongoDB

~~~
MongoDB 是文档型数据库，核心在于Schema-free（无模式）和水平扩展。

核心使用场景：
    半结构化数据：存储商品详情、用户画像、日志数据，字段可随时增减，无需像 MySQL 那样改表结构。
    海量数据存储：通过分片（Sharding）技术，轻松支撑 TB/PB 级数据（如 BI 报表数据、历史订单归档）。
    地理位置服务：内置 Geo 索引，轻松实现“附近的人”、“配送范围计算”。
    
深度优化：
    索引设计：MongoDB 对索引依赖极高。需掌握复合索引、覆盖索引查询，避免全表扫描（COLLSCAN）。
    分片策略：选择合适的片键（Shard Key）至关重要。片键选择不当会导致数据倾斜（数据都集中在一个分片上）或查询广播（查询所有分片）。
    写入优化：利用批量写入（Bulk Write）提升吞吐量。
~~~
