## 预审流程
~~~
1.上传图纸，保存到Minio中（保留图纸的url地址）
2.上传成功后开始预审

通过责任链方式、创建五个方法，按照设置的责任链顺序执行
预审流程：
1.C++导图（把DWG文件解析成图源）
2.图框、图签、计算书坐标检测（找图框，图签（整个最右边一列）（子项名称））
3.图源数统计、拆分图源（所有图源拆到图框、md5）
4.CV图签精准识别检测（CV去精准识别图签信息（图签只有左下角），CV会去除相关图源）
5.多模态识别（截图，大模型识别图片上的信息）（图源里面的文字、多模态返回的文字比较  动态规划修改文字）

主要存储 图源、图签、图框信息

在容器初始化的会创建好所有专业的step步骤，在每个step上面的都会有@Component
在审图会选用某个专业获取执行对应的ReviewSteps

## 业务变量展示
~~~
@Documented
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
public @interface ShowField {

    // 自定义展示的信息
    String label() default "";

    /**
     * 支持多个  ,分割
     *
     * @return
     */
    String labelField() default "";

    // 展示对象或者list处理
    boolean child() default false;

    /**
     * 坐标类型展示
     *
     * @return
     */
    CoordinateTypeEnum coordinateType() default CoordinateTypeEnum.NONE;

    boolean isMap() default false;
}
