# 二叉树

~~~
二叉树，每个节点最多有两个叉，也就是两个子节点，分别是左子节点和右子节点。
二叉树不要求每个节点都有两个子节点，有的节点只有左子节点，有的节点只有右子节点。
二叉树每个节点的左子树和右子树也满足二叉树的定义。
~~~

## 类别
~~~
满二叉树
安全二叉树
二叉搜索树
红黑树
~~~

## 二叉搜索树
~~~
Binary Search Tree，也叫二叉排序树，是一种特殊的二叉树，它满足以下性质：
1. 左子树中的每个节点的值都小于它的根节点的值。
2. 右子树中的每个节点的值都大于它的根节点的值。
3. 左右子树也分别为二叉搜索树。

二叉搜索树的查找、插入和删除操作的时间复杂度都为O(log n)。

~~~

## 红黑树
~~~
红黑树（red-black tree）是一种自平衡的二叉搜索树，它满足以下性质：
1. 每个节点或者是红色的，或者是黑色的。
2. 根节点是黑色的。
3. 每个叶子节点（即空节点）是黑色的。
4. 如果一个节点是红色的，则它的子节点必须是黑色的。
5. 从一个节点到该节点的子孙节点的所有路径上包含相同数目的黑色节点。

    红黑树的插入、删除操作的时间复杂度都为O(log n)。
~~~
